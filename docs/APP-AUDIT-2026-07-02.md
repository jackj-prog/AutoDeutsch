## 2. What the app physically is (re-measured)

- **`src/app.jsx` — 6,717 lines**, one `App()` component holding **114 `useState` + 43 `useRef`
  (157 hooks) and 31 `useEffect`**. Plus the two extracted modules: `src/lib/palette.js` (10 lines)
  and `src/components/icons.jsx` (141 lines), concatenated **before** app.jsx by the build into one
  IIFE scope (alphabetical order within each dir — the TDZ ordering trap in `MODULARIZATION-PLAN.md` §0c).
- **`src/data.js` — 9,300 lines / 1.3 MB**, 12 datasets (`V` is an object of 36 category arrays,
  not a flat list).
- **JSX is compiled at build time** — `build-static.mjs` runs @babel/standalone in Node; the browser
  loads the precompiled `app.js` (no in-browser Babel; see doc-drift §5).
- **15 screens** behind one `screen` state: home, train, cards, drill, sentence, audio, browse,
  dialogues, library, scenarios, mission, roleplay, tutor, stats, results — plus a real back-stack
  (`goBack`/`goRoot`).
- Bundle: `app.js` 362 KB raw / **87 KB gz**; `data.js` 1.3 MB raw / **380 KB gz**. Both SW-cached
  for offline; fine for a PWA, no code-split needed.
- PWA plumbing is sound: content-hash SW cache name (auto-bumped by the build), network-first app
  shell that keeps index.html/app.js/data.js in **SRI lockstep** (stale-pairing = blank screen is
  designed against), update check on load / every 5 min / on focus, `controllerchange` reload,
  maskable icons, notification-click handling for the daily reminder.

2. **"Babel compiles JSX in the browser" is stale** (`CLAUDE.md` mental model; also the analysis
   doc §1). Since the static build, Babel runs **in Node at build time** and the browser loads the
   precompiled, SRI-pinned `app.js`. The operational rule is unchanged (edit `src/`, run the build),
   but the mental model line misleads.
3. Trivial: analysis doc says 158 hooks / 32 effects; today it's 157 / 31 (file unchanged since —
   just counting-method noise). Not worth acting on.

## 6. Risk register (unchanged from the last audit — structural, not bugs)

- 🟡 **The monolith** — `App()` is ~5.7k lines / 157 hooks. Works; slows change. Mitigation path
  proven (`palette.js`, `icons.jsx`); next mechanical step is `src/lib/constants.js`. Low urgency.
- 🟡 **`gfc-*` keys are the account** — no server; renaming strands every user. Any unification must
  be a shipped read-old-write-new migration (pattern: `ad-level-mig-v1`).
- 🟢 **CDN dependency** — React/fonts load from cdnjs/Google on first visit (SRI-pinned, SW-cached
  after). Acceptable; a cdnjs outage only affects brand-new visitors.
- 🟢 **BYOK in localStorage** — standard tradeoff; no XSS surface found to exploit it.
